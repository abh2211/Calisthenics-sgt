# Calisthenics-SGT

Landing page for Calisthenics-SGT, coached calisthenics small-group training with Annur at The Gym Group, West12.

- `index.html`: the whole page, a single self-contained file. The photos are embedded at the end of the file.
- `images/`: the original web-sized photos, kept as editable copies.

Editable details (price, start date, contacts, quotes, photos) live in the `CONFIG` object near the bottom of `index.html`.

The form sends enquiries by email through FormSubmit. It must be activated once from the live site before it delivers messages.
